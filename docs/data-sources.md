## 版の注意

`s_20260501.csv`の10,192件は令和6年度版です。同じ2026年5月1日には令和8年度改定対応の医科診療行為マスターも公開されているため、ファイル名の日付だけでは版を確定できません。件数、適用期間、取得元ページをセットで記録します。

傷病名・修飾語は診療報酬改定と同じ周期だけで更新されるとは限りません。このPoCでは「制度改定」と「配布ファイルの更新日」を同じ概念として扱いません。

## ローカルで記録する情報

配布ファイルを取得したら、次を保存します。

- 取得元URL
- 取得日時
- 掲載されていた更新日・適用期間
- ファイル名
- バイト数
- SHA-256

```powershell
py src/hash_sources.py data/private --output work/source-manifest.csv
```

SHA-256は内容の同一性を確認するための値であり、出典や正しさを証明するものではありません。

## 利用条件

傷病名・修飾語マスターの公式ページは、名称・コード等を改変しないことを条件に、頒布を含む使用や、一部抽出・他情報を付加した複製物の作成を認めています。ただし本リポジトリでは、版の混同と不要な複製を避けるため元ファイルを収蔵しません。利用時は公式ページの最新の「利用上のお願い」「免責事項」を確認してください。
