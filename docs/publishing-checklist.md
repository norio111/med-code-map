# 公開前チェックリスト

- [ ] `py -m unittest discover -s tests -v`が成功する
- [ ] `data/private/`、`work/`、生成DB、取得PDFがGit対象に入っていない
- [ ] `git status --short`で意図しないファイルがない
- [ ] READMEの対象版・件数・適用期間が、取得元ページと一致する
- [ ] 区分番号・施設基準の手入力名称を、点数表等の原典と再照合する
- [ ] `index.html`の集計値を、同じ入力ファイルから再計算できる
- [ ] 個人情報、患者情報、職場内部資料、APIキーが含まれていない
- [ ] 公開条件を決め、必要なら`LICENSE`を追加する

## GitHubへ公開するとき

この配布物には`LICENSE`を意図的に入れていません。ライセンスは、第三者に
再利用・改変・再配布をどこまで認めるかを本人が決めてから追加します。

公開リポジトリを新規作成する場合、公式マスターを含む元リポジトリではなく、
この公開用ディレクトリをGit管理してください。GitHubの公開画面でも、最初の
push前に`git status`と`git ls-files`を再確認します。
