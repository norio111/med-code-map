## 観測1：点数が変わったコードは0件

継続した97件は、すべて点数が据え置き。名称変更も0件、1日上限単位（きざみ上限値）の変更も0件、施設基準の要求の変更も0件だった。

この改定の変化は、既存コードの値の書き換えではなく、**コードの入れ替え**として現れている。

## 観測2：消滅75件のうち72件が「（リ減）」

R06には「（リ減）」を名称に含むコードが存在し、その72件がR08には無い。R08の単位系210件に「（リ減）」を含むものは1件も無い。

```
180748030  脳血管疾患等リハビリテーション料（１）（作業療法士）（リ減）  221点
…
```

減算後の点数を別コードとして持つ方式が、R08では使われていない。減算がどう表現されるようになったかは、このマスターだけでは確定できない。

## 観測4：加算が疾患別に分割された

早期リハビリテーション加算は、R06では1コードだった。

```

```

R08では、疾患別リハビリテーションごと、かつ算定日数帯ごとに10コードへ分かれている。

```
R08  180762470  早期リハビリテーション加算（心大血管疾患リハ）          60点
R08  180762570  早期リハビリテーション加算（４日目以降）（心大血管疾患リハ）  25点
R08  180763870  早期リハビリテーション加算（脳リハ）                  60点
R08  180763970  早期リハビリテーション加算（４日目以降）（脳リハ）        25点
…（廃用症候群・運動器・呼吸器も同じ形）
```

初期加算、急性期リハビリテーション加算、休日リハビリテーション加算も同様に、疾患別へ分割されている。

## この比較で言えないこと

- 新しい版に無いコードが「廃止された」のか「配布対象から外れた」のかは、この2版の比較だけでは区別できない。R08の入力は廃止年月日が全件`99999999`であり、廃止済みコードを含まない配布物である。
- 名称の対応関係（脳血管疾患等リハビリテーション料 → 脳リハ）は、文字列の類似から読んだものであり、マスター上に移行関係として記録されているわけではない。診療行為マスターには、傷病名マスターの移行対応表に相当するものが無い。
- 減算や患者区分の実際の算定要件は、告示・通知の側にある。ここで観測できるのはコードの増減だけである。
